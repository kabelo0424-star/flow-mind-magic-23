# Flow Mind Magic

Build a full web application using this prompt:

Prompt: AI Productivity Assistant Dashboard

Role: Act as an expert AI developer and UI/UX designer.

Objective: Build a modern, interactive AI productivity dashboard that combines a Meeting Note Summarizer, AI Task Planner, and AI Research Assistant.

Context: The platform helps students, professionals, and teams save time, organize work, and improve productivity in one central workspace.

Requirements:

Meeting Note Summarizer: Summarize meetings, extract key decisions, identify action items, and generate follow-up notes.

AI Task Planner: Create and prioritize tasks, set deadlines, manage schedules, and track progress.

AI Research Assistant: Research topics, summarize findings, compare information, and provide reliable sources with citations.

AI Chat Assistant: Answer questions and connect meeting notes, tasks, and research.

Dashboard: Include navigation, upcoming deadlines, recent meetings, task statistics, and research projects.

Design: Use a professional, responsive interface with modern colors, interactive cards, charts, and light/dark modes.

Functionality: Include data storage, secure AI integrations, error handling, and working buttons.

Output: Deliver a complete, responsive, interactive website called MindFlow AI that allows users to summarize meetings, plan tasks, conduct research, and track productivity from one dashboard. Use realistic sample data and provide setup instructions.
